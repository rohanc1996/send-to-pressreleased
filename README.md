Based on PressReleased created by AbsoluteXYZero, inspired and built on Magnolia1234’s BypassPaywallsClean browser extension and Danny-Dasilva's CycleTLS.

Press Released requires you to copy-paste the link you want to bypass the paywall on, so I thought I'd just create a simple but useful extension that works around that and still allows folks to use the tool.

Click the extension button while viewing an article to open the reader. The reader includes controls for system/light/dark themes, four text-size levels, and narrow/wide layouts. Preferences are saved for future articles. Press `Escape` or use **Close reader** to exit.

The reader shows a loading state while retrieving content, prevents duplicate requests, and provides specific messages for timeouts, unsupported pages, and rate limits. Local/private URLs and URLs containing credentials or likely access tokens require confirmation before they are sent to the PressReleased service. The current development build identifier is shown at the bottom of the reader.

Run the automated checks with `npm test`. See [CHANGELOG.md](CHANGELOG.md) for release history.

⚠️ For educational purposes only. Respect content creators and consider subscribing to publications you read regularly.
